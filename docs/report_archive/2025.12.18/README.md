## 保留策略

### 保留期限

- **标准保留**: 2 年（至 2027-12-18）
- **重要文档**: 5 年（需特别标注）
- **历史记录**: 永久保留（需特别标注）

### 删除策略

- **2 年后**: 可删除一般归档文档
- **5 年后**: 可删除标记为重要的文档
- **永久保留**: 架构决策、历史重要节点文档

### 恢复指南

如果需要恢复归档文档：

1. 从 `report_archive/YYYY.MM.DD/` 目录复制
2. 更新文档头部元数据
3. 检查内容时效性
4. 更新 `docs/report/README.md` 索引
