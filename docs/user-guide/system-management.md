## 租户管理

### 租户功能概述

租户管理是 AlkaidSYS 多租户架构的核心功能，支持在同一系统中管理多个独立的租户实例。每个租户拥有独立的数据隔离、用户配额和配置选项。

**主要功能**:
- 租户的增删改查
- 租户状态管理（启用/停用/暂停）
- 租户配额管理（站点数、用户数）
- 租户有效期管理

**访问路径**: `系统管理 > 租户管理`

**权限要求**:
| 操作 | 所需权限 |
|------|----------|
| 查看租户列表 | `tenant.read` |
| 创建租户 | `tenant.write` |
| 编辑租户 | `tenant.write` |
| 删除租户 | `tenant.delete` |
| 切换状态 | `tenant.write` |

### 租户列表

租户列表页面展示所有租户的基本信息，支持搜索和筛选。

**列表字段说明**:

| 字段 | 说明 |
|------|------|
| ID | 租户唯一标识 |
| 租户名称 | 租户显示名称 |
| 租户标识 | 租户唯一标识符（slug），用于 URL 和 API 调用 |
| 绑定域名 | 租户专属域名（可选） |
| 状态 | 租户当前状态：启用/停用/暂停 |
| 最大站点数 | 租户可创建的最大站点数量 |
| 最大用户数 | 租户可创建的最大用户数量 |
| 到期时间 | 租户服务有效期 |
| 创建时间 | 租户创建时间 |

**搜索筛选**:
- 按租户名称搜索
- 按租户标识搜索
- 按状态筛选
- 按绑定域名搜索

### 创建租户

点击列表页面的「新增」按钮，在弹出的表单中填写租户信息。

**表单字段**:

| 字段 | 必填 | 说明 |
|------|------|------|
| 租户名称 | 是 | 租户显示名称，建议使用公司/组织名称 |
| 租户标识 | 是 | 唯一标识符，只能包含小写字母、数字、下划线和连字符 |
| 绑定域名 | 否 | 租户专属域名，如 `tenant1.example.com` |
| 状态 | 是 | 默认为「启用」，可选：启用/停用/暂停 |
| 最大站点数 | 否 | 默认 1，范围 1-100 |
| 最大用户数 | 否 | 默认 10，范围 1-10000 |
| 到期时间 | 否 | 租户服务有效期，留空表示永久有效 |

**租户标识规则**:
- 只能使用小写英文字母 (a-z)
- 可以使用数字 (0-9)
- 可以使用下划线 (_) 和连字符 (-)
- 必须全局唯一
- 示例：`company_a`、`tenant-01`、`acme2024`

### 编辑租户

在租户列表中，点击对应行的「编辑」按钮，修改租户信息后保存。

> **注意**: 租户标识（slug）创建后不可修改，如需更改请删除后重新创建。

### 删除租户

在租户列表中，点击对应行的「删除」按钮，确认后删除租户。

> **警告**: 删除租户将同时删除该租户下的所有数据，此操作不可恢复，请谨慎操作！

### 切换租户状态

可以直接在列表中点击状态开关切换租户状态。

**状态说明**:

| 状态 | 标签颜色 | 说明 |
|------|----------|------|
| 启用 (active) | 绿色 | 租户正常运行，用户可正常访问 |
| 停用 (inactive) | 灰色 | 租户已停用，用户无法访问 |
| 暂停 (suspended) | 红色 | 租户被暂停，通常因违规或欠费 |

切换状态时会弹出确认对话框，确认后状态立即生效。

## 角色管理

### 角色功能概述

角色管理用于定义系统中的角色及其权限。采用 RBAC（基于角色的访问控制）模型，通过为用户分配角色来控制其权限。

**主要功能**:
- 角色的增删改查
- 角色权限配置
- 系统角色与自定义角色区分

**访问路径**: `系统管理 > 角色管理`

**权限要求**:
| 操作 | 所需权限 |
|------|----------|
| 查看角色列表 | `role.read` |
| 创建角色 | `role.write` |
| 编辑角色 | `role.write` |
| 删除角色 | `role.delete` |
| 角色授权 | `role.write` |

### 角色列表

角色列表页面展示所有角色的基本信息。

**列表字段说明**:

| 字段 | 说明 |
|------|------|
| 角色ID | 角色唯一标识 |
| 角色名称 | 角色显示名称 |
| 角色标识 | 角色唯一标识符（slug），用于权限判断 |
| 备注 | 角色描述信息 |
| 类型 | 系统角色或自定义角色 |
| 权限 | 角色拥有的权限数量 |
| 创建时间 | 角色创建时间 |

**角色类型**:
- **系统角色** (蓝色标签): 系统内置角色，不可编辑和删除
- **自定义角色** (灰色标签): 管理员创建的角色，可自由编辑

### 创建角色

点击列表页面的「新增」按钮，在弹出的表单中填写角色信息。

**表单字段**:

| 字段 | 必填 | 说明 |
|------|------|------|
| 角色名称 | 是 | 角色显示名称，如「运营主管」「客服专员」 |
| 角色标识 | 是 | 唯一标识符，只能包含小写字母、数字、下划线和连字符 |
| 备注 | 否 | 角色功能描述 |

**角色标识规则**:
- 只能使用小写英文字母 (a-z)
- 可以使用数字 (0-9)
- 可以使用下划线 (_) 和连字符 (-)
- 必须全局唯一
- 示例：`admin`、`editor`、`sales_manager`

### 编辑角色

在角色列表中，点击对应行的「编辑」按钮，修改角色信息后保存。

> **注意**:
> - 系统角色不可编辑
> - 角色标识（slug）创建后不可修改

### 删除角色

在角色列表中，点击对应行的「删除」按钮，确认后删除角色。

> **警告**:
> - 系统角色不可删除
> - 删除角色前请确保没有用户正在使用该角色
> - 删除操作不可恢复

### 角色授权

点击角色列表中的「授权」按钮，为角色配置权限。

**权限分类**:

| 分类 | 包含权限 |
|------|----------|
| 租户管理 | 租户的读取、写入、删除权限 |
| 角色管理 | 角色的读取、写入、删除权限 |
| 用户管理 | 用户的读取、写入、删除权限 |
| 表单管理 | 表单的读取、写入、删除权限 |
| 集合管理 | 数据集合的读取、写入、删除权限 |
| 权限引擎 | Casbin 权限引擎管理权限 |

**授权步骤**:
1. 点击角色行的「授权」按钮
2. 在弹出的权限配置面板中勾选需要的权限
3. 点击「确定」保存权限配置

权限以树形结构展示，可以按资源类型批量选择。

## API 接口参考

### 租户管理 API

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/v1/admin/tenants` | 获取租户列表 | `tenant.read` |
| GET | `/v1/admin/tenants/:id` | 获取单个租户 | `tenant.read` |
| POST | `/v1/admin/tenants` | 创建租户 | `tenant.write` |
| PUT | `/v1/admin/tenants/:id` | 更新租户 | `tenant.write` |
| DELETE | `/v1/admin/tenants/:id` | 删除租户 | `tenant.delete` |
| PATCH | `/v1/admin/tenants/:id/status` | 切换租户状态 | `tenant.write` |

### 角色管理 API

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/v1/admin/roles` | 获取角色列表 | `role.read` |
| GET | `/v1/admin/roles/:id` | 获取单个角色 | `role.read` |
| POST | `/v1/admin/roles` | 创建角色 | `role.write` |
| PUT | `/v1/admin/roles/:id` | 更新角色 | `role.write` |
| DELETE | `/v1/admin/roles/:id` | 删除角色 | `role.delete` |
| PUT | `/v1/admin/roles/:id/permissions` | 设置角色权限 | `role.write` |
| GET | `/v1/admin/permissions` | 获取所有权限 | `role.read` |

## 常见问题

### Q: 为什么无法编辑某些角色？

A: 系统角色（标记为蓝色标签）是内置角色，不允许编辑和删除，以保证系统基础功能正常运行。

### Q: 删除租户后数据能恢复吗？

A: 不能。删除租户会同时删除该租户下的所有数据，请在删除前做好数据备份。

### Q: 租户标识可以修改吗？

A: 不能。租户标识（slug）创建后不可修改，因为它可能被用于 URL、API 调用等场景。如需更改，请删除后重新创建。

### Q: 如何给用户分配角色？

A: 请前往「用户管理」页面，编辑用户时可以选择分配的角色。
