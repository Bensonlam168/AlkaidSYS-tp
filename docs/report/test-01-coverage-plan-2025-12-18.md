# TEST-01 覆盖率提升计划（2025-12-18）

## 目标

- 整体覆盖率 ≥ 80%，关键模块（认证/权限/多租户/低代码） ≥ 90%
- 核心 E2E 流程 100% 自动化

## 现状（参考全面审查报告）

- 整体约 75%
- 关键模块覆盖率：认证权限 ~85%，多租户 ~90%，低代码 ~65%
- PHPUnit 配置与元数据弃用已清理（T-121 完成，phpunit.xml 11.5 schema，@covers → 属性）

## 缺口与优先补齐路径

1. **认证/权限**
   - 补充 JWT 错误路径、过期/撤销、租户切换场景
   - 权限校验缓存命中/降级路径（与 PERF-01 协同）
2. **多租户**
   - BaseModel 全局作用域在复杂查询/联表下的覆盖
   - TenantIdentify 中间件异常路径（缺 header、站点切换）
3. **低代码**
   - Collection/FormDesigner CRUD 跨租户隔离
   - 动态表结构（SchemaBuilder）异常路径与回滚
4. **E2E**
   - 核心业务链路：登录 → 低代码表单创建 → 数据提交 → 权限校验

## 行动计划

- **D1（覆盖率扫描）**：使用现有报告基础，按模块列出未覆盖文件/函数（优先：低代码）。
- **D2（用例补齐）**：优先补齐低代码与权限缓存相关用例；为多租户/认证的异常路径增加 Feature/E2E。
- **D3（CI Gate）**：设置覆盖率阈值并在 CI 中启用（总 ≥80%，关键模块 ≥90%），允许阶段性软门禁。
