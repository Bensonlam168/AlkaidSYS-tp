### 6. 端到端集成分析

#### 设计要求

根据`51-form-collection-workflow-end-to-end.md`，端到端流程应为：

```
用户提交表单 → 数据建模入库 → 工作流触发 → 节点执行 → 结果回写
```

**6.1 完整流程**
1. 用户在前端低代码表单页面填写并提交表单
2. 后端表单网关接口校验表单Schema，写入对应的Collection实例表
3. 写入成功后，表单模块发布领域事件
4. 工作流引擎的触发器订阅这些事件，根据配置匹配需要启动的工作流
5. 工作流引擎创建执行上下文，初始化变量，基于表达式引擎驱动节点流转
6. 各个节点执行完成后，必要时回写业务表或发布新的领域事件

**6.2 多租户支持**
- 整个链路中必须始终携带`tenant_id/site_id/user_id`
- 在每一层做隔离与权限校验

**6.3 事件驱动架构**
- `lowcode.form.submitted` - 表单提交事件
- `lowcode.collection.data.created` - 数据创建事件
- `lowcode.collection.data.updated` - 数据更新事件

#### 当前实现

**实现状态**:

- ❌ 无表单模块集成
